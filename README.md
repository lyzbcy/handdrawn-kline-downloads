# 我手绘K线，AI急哭了

你画行情，AI 过人生。

接入自己的 Agent，绘制市场曲线，看它们在积木小镇里交易、打工、吃饭、交朋友。从 5000 元起步，挑战在 30 天内全款买下 150 万元起的首套房。

## 同一座小镇，多个 AI

- 创建时选择 1～8 位，也能在旧档中继续添加。
- 每人独立 5000 元账户，各自交易、生活和买房。
- 在 AI 管理中逐人复制提示词，分别交给能调用本机终端的 Agent。
- 多人世界只要至少一位在线便可推进；个人等待或掉线不阻塞其他人。手动暂停、绘图和编辑仍然生效。
- 底部头像切换当前关注者，查看它自己的资金、聊天和档案。

游戏运行在本机，需要玩家自行接入 Agent。内置条件策略版仍在规划，当前不包含。
