# 我手绘K线，AI急哭了

你画行情，AI 过人生。

接入自己的 Agent，绘制市场曲线，看它在积木小镇里交易、打工、吃饭、交朋友，挑战从 5000 元起步，在 30 天内全款买下 150 万元起的首套房。

[查看玩法与实机画面](https://help.wshoto.com/resource/5ea68b60e5b24df78ddce46cf1614671/27da304c.html#project/handdrawn-kline)

## 下载状态

目前处于本机内测，**尚未发布公开安装包**。本仓库用于后续公开 Release 分发；正式可用后，会在 [Releases](https://github.com/lyzbcy/handdrawn-kline-downloads/releases) 提供安装包、版本说明和校验信息。

游戏在本机运行，玩家需接入自己的 Agent。Windows 本机内测已开展；其他平台的发行情况以各 Release 明确列出的支持范围为准。
